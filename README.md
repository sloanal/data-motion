# Data Motion

A multi-user visualization sandbox for exploring schedule synchronization,
cross-network sharing, permissions, dependencies, and approval workflows.

## Development

```bash
npm install
npm run dev
```

## Deployment

Publish the current `main` branch to GitHub Pages:

```bash
npm run deploy
```
